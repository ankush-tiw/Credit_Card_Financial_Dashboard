# Credit_Card_Financial_Dashboard
1. Project Objective
To build an interactive Power BI dashboard providing a Weekly Card Status Report that monitors key financial metrics (revenue, transaction volumes, interest) and tracks week-over-week (WoW) trends to empower data-driven decision-making.

2. Dataset
The project utilizes financial data split into two primary tables:

Credit Card Data: Transaction amounts, card categories (Blue, Silver, Gold, Platinum), interest earned, and usage types.

Customer Data: Cardholder demographics including age, gender, income group, and occupation.

3. Steps
Data Extraction: Pulled raw data from the database using SQL.

ETL Processing: Cleaned and transformed data using Power Query (handling missing values, standardizing formats).

Data Modeling: Established a Star Schema connecting fact and dimension tables.

DAX Calculations: Built custom measures to calculate WoW growth, rolling averages, and demographic segmentation.

Visualization: Designed an intuitive interface with interactive KPIs, line charts, and matrix visuals.

4. Insights
Revenue Tracking: Identified peak spending periods and overall WoW financial growth.

Card Performance: Revealed which card tiers drive the highest transaction volume versus the highest interest earned.

Customer Segmentation: Pinpointed the specific demographic profiles (age, income level) generating the majority of the revenue.

5. Action Items
Targeted Marketing: Launch customized campaigns focused on the highest-revenue-generating customer segments.

Tier Upselling: Incentivize high-frequency users on base-level cards to upgrade to premium tiers to capture higher annual fees.

Channel Promotions: Partner with online retailers to offer exclusive cashback rewards if digital transaction volumes show strong growth.
